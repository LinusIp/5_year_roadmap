# Image classifier fine-tune with a Gradio demo on Hugging Face Spaces

**Goal.** A pretrained vision model fine-tuned on a dataset you gathered and cleaned yourself, evaluated on a held-out test split, and published as a public Gradio app on Hugging Face Spaces.

**Why.** Transfer learning is how most real vision problems get solved, and doing it on your own data teaches data cleaning better than any benchmark. It builds transfer learning, data cleaning and Gradio, and touches `inference-engineering/fine-tuning`, `ai-engineer/benefits-of-pre-trained-models`, `ai-engineer/hugging-face-hub`, `ai-engineer/hugging-face-models` and `ai-engineer/image-understanding`.

**Scope.** MVP: 3–10 classes with 100–300 images each that you gathered (your photos, or a scrape with licences noted), deduplicated and checked by hand; a stratified train, validation and test split; a fine-tuned ResNet, ConvNeXt or ViT; a confusion matrix and a gallery of failures; a Gradio app on Spaces loading the model from the Hub. Stretch: a cleaning pass driven by the model's own top losses, test-time augmentation, an ONNX export for faster CPU inference.

**Architecture.** A collection script imports images and writes a manifest. A cleaning notebook removes near-duplicates by perceptual hash and fixes mislabels. The training script loads a pretrained backbone, replaces the head, trains the head and then the whole network at a lower learning rate, and logs metrics. An evaluation script produces the confusion matrix and the failure gallery. The Gradio app returns the top-3 classes with probabilities.

```
collect ─▶ clean (dedupe, relabel) ─▶ split ─▶ fine-tune ─▶ model on the Hub
                                                   │                 │
                                  eval: confusion matrix, failures   Gradio Space
```

**Stack.** Python 3.12, PyTorch with timm or fastai, imagehash, Matplotlib, Hugging Face Hub and Spaces, Gradio.

**Milestones.** Collect and label the dataset (5 h) · clean, deduplicate and split (3 h) · fine-tune two backbones (5 h) · evaluation, confusion matrix and failure gallery (3 h) · Gradio app on Spaces and README (4 h). Total 20 h.

**Done when.** The test split, with at least 30 images per class, is held out from every choice. The fine-tuned model beats a linear probe on frozen features, with test accuracy and per-class F1 reported. The confusion matrix and at least 12 failure cases are in the README with a sentence on each pattern. The public Space classifies an uploaded image in under 3 seconds on the free CPU tier.

**Measure and report.** Test accuracy and macro F1 for the linear probe and both fine-tuned backbones; the confusion matrix; how many images cleaning removed and why; Space inference latency p50 and p95 over 50 images.

**Pitfalls.** Near-duplicates landing in both train and test and inflating accuracy. A class that is really "photos taken indoors" rather than the object. A learning rate too high for the backbone, wrecking the pretrained features. Forgetting the backbone's input normalisation in the Gradio app. A Space that fails to build because dependencies are not pinned.

**References.** fastai-practical-dl, stanford-cs231n, paper-resnet, kaggle-learn, w-ml-cnn-visualise.

**Write-up.** The Space link at the top, a screenshot of one prediction, the results table, the confusion matrix, the failure gallery, and what data you would collect next.
