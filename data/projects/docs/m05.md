# micrograd clone and MNIST from scratch in NumPy

**Goal.** A scalar reverse-mode autodiff engine written by you, with gradient tests, and a NumPy multilayer perceptron trained by your own SGD to at least 97 % test accuracy on MNIST.

**Why.** Backpropagation stops being magic when you write it twice: once on scalars, once on arrays. It builds backpropagation, NumPy and gradient checking, and the roadmap nodes `inference-engineering/neural-networks` and `ai-engineer/training`. Every model later in the plan rests on it.

**Scope.** MVP: a `Value` class with addition, multiplication, power, tanh, ReLU, exp and log, a topologically ordered `backward()`, and a tiny neural-net module on top; then a vectorised NumPy MLP (784 → hidden → 10) with softmax cross-entropy, mini-batch SGD, weight initialisation and an evaluation loop. No deep-learning framework. Stretch: momentum and Adam, dropout, a graph visualiser with graphviz, a tensor version of the autodiff engine.

**Architecture.** Part 1: each `Value` stores its data, its grad, its parents and a local backward closure; `backward()` sorts the graph topologically and runs the closures in reverse. Part 2: layers are NumPy arrays with hand-written forward and backward functions; the training loop shuffles, batches, steps and logs; a gradient checker compares each layer's backward with central differences on a small batch.

```
Value graph:  x ─┐
              w ─┼─▶ * ─▶ + ─▶ tanh ─▶ loss ─▶ backward() fills .grad
              b ─┘
MNIST: batch ─▶ Linear ─▶ ReLU ─▶ Linear ─▶ softmax-CE ─▶ grads ─▶ SGD
```

**Stack.** Python 3.12, NumPy, pytest, Matplotlib; PyTorch only inside tests, as a gradient reference; MNIST read from the raw IDX files.

**Milestones.** Value class, operators and backward with tests (6 h) · neuron, layer and MLP on a toy dataset (4 h) · NumPy layers with forward, backward and gradient check (7 h) · MNIST loader, training loop and evaluation (6 h) · hyperparameter runs, curves and write-up (7 h). Total 30 h.

**Done when.** For 20 random expressions, your gradients match central differences to a relative error below 1e-6 and match PyTorch autograd. Every NumPy layer passes the gradient check below 1e-5 in float64. The MLP, trained with your own SGD, reaches at least 97 % accuracy on the 10 000 MNIST test images, with training and validation curves saved and a fixed seed that reproduces the result.

**Measure and report.** Test accuracy (best run, and mean over 3 seeds); train and validation loss per epoch; the effect of learning rate (3 values), hidden width (2 values) and batch size (2 values), with one sentence each on what it did; time per epoch.

**Pitfalls.** Gradients overwritten instead of accumulated when a node is used twice. Forgetting to zero gradients between steps. Softmax overflow when the row maximum is not subtracted. Gradient checks in float32 with an epsilon too small, then chasing noise. Normalising the test set with its own statistics instead of the training set's.

**References.** karpathy-zero-to-hero, d2l, udl-book, deep-learning-book, w-ml-gradient-check.

**Write-up.** The loss and accuracy curves, a table of hyperparameter runs, a drawing of one small computation graph with its gradients, and the misclassified digits that surprised you.
