# Zoomcamp capstone and a tool-using agent (HF Agents final)

**Goal.** Two submitted deliverables: the ML Zoomcamp capstone (a second, harder end-to-end ML project, deployed and peer-reviewed) and the Hugging Face Agents course final, an agent with at least three tools that completes multi-step tasks, scored on 15 recorded test tasks.

**Why.** The capstone repeats the midterm loop (`ai-engineer/training`, `ai-engineer/inference`, `inference-engineering/containerization`) with less hand-holding. The agent builds tool use, agent loops and evals: `ai-agents/agent-loop`, `ai-agents/what-are-tools`, `ai-agents/web-search`, `ai-agents/code-execution-repl`, `ai-agents/file-system-access` and `ai-agents/metrics-to-track`. Together they close the first phase with two certificates.

**Scope.** MVP: a capstone on a new dataset (ideally images or text, so it differs from the midterm) with a service, Docker and a deploy; an agent with web search, a Python code executor and file access (or an API), a 15-task test set and a pass-or-fail log per run; the course's final assessment. Stretch: deploy the capstone on a local Kubernetes (kind), add a memory tool to the agent, compare two models on the same 15 tasks.

**Architecture.** The capstone reuses the midterm pipeline: notebook, `train.py`, artefact, prediction service, container. The agent is a loop: the model reads the task and the tool descriptions, emits a tool call, the runtime executes it in a sandbox and feeds back the observation, until the model returns a final answer or hits a step limit. A test runner replays the 15 tasks, checks each answer against an expected result and appends a row to a results file with the commit hash.

```
task ─▶ LLM ─▶ tool call ─▶ [search | python | files] ─▶ observation
         ▲                                                   │
         └───────────────────────────────────────────────────┘
                   final answer ─▶ checker ─▶ results.csv
```

**Stack.** Python 3.12; scikit-learn or PyTorch, FastAPI and Docker for the capstone; smolagents (the course framework) or LangGraph, a hosted or local instruct model, DuckDuckGo search and a restricted Python executor for the agent.

**Milestones.** Capstone dataset, EDA and model comparison (10 h) · capstone service, Docker, deploy and peer review (8 h) · Agents course units and an agent with three tools (10 h) · 15-task test set and runner (6 h) · course final assessment, certificate and write-up (6 h). Total 40 h.

**Done when.** The capstone is submitted, deployed at a public URL, and has passed peer review. The agent solves at least 10 of the 15 test tasks, each needing at least two tool calls, and `results.csv` records pass or fail per task per commit so two versions can be compared. The Hugging Face Agents course certificate is earned and linked from the README.

**Measure and report.** Capstone held-out metric and its gap over the baseline. For the agent: pass rate on the 15 tasks, mean tool calls and tokens per task, wall-clock time per task, and failures by category (wrong tool, bad arguments, loop, hallucinated answer).

**Pitfalls.** Scoping the capstone too large and leaving no time for the agent. Code execution without a sandbox or a timeout. Test tasks whose answers drift (live web pages), so pass rates change with no code change. A step limit set too high, so a looping agent burns tokens. Grading by eye instead of with a checker.

**References.** ml-zoomcamp, cert-ml-zoomcamp, hf-agents-course, cert-hf-agents, paper-react, paper-toolformer.

**Write-up.** Two sections: the capstone (URL, results table, sample request) and the agent (a trace of one solved task, the 15-task table, what failed and why).
