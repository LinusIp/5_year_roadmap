# Illustrations

Every image in this folder is listed in `art.json` with its source and licence, and here. Only images the user has
the rights to ship: ones they generated or made, or ones under a licence that allows use in an app (Unsplash licence,
Pexels licence, CC0). Nothing is downloaded or copied from Pinterest, Instagram or any other site.

Until images arrive, every slot shows a placeholder drawn by the app (`src/ui/ArtPlaceholder.tsx`): soft washes and
brush-stroke silhouettes in the theme's own colours. The prompts for a matching set are in the brief
(ATLAS-ART-IMAGE-PROMPTS): name each file after its slot, put the originals in `art-src/` and run
`npm run art:build` to write the AVIF and WebP files here and their rows into `art.json`.
