# Audio

Atlas ships no audio files. The Focus tab's "Atlas sounds" (white, pink and brown noise, soft rain, an ambient pad)
are generated in the browser with the Web Audio API (`src/lib/sounds.ts`), so nothing here needs a licence.
YouTube sessions play only through the official embed player on `youtube-nocookie.com`; nothing is downloaded,
ripped or re-hosted.

Any file added to this folder must be generated by the app or carry a licence that allows it (CC0, or the Pixabay
content licence), and be listed here with its source.
